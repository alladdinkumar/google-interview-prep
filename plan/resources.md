## Reference Books (free PDFs widely available)

- **Galvin OS** — Operating System Concepts (Silberschatz/Galvin)
- **Korth DBMS** — Database System Concepts
- **Tanenbaum CN** — Computer Networks
- **CLRS** — Introduction to Algorithms (reference only, not for prep)
- **Designing Data-Intensive Applications** (Kleppmann) — best book for HLD theory; read selected chapters in Phase 4
- **System Design Interview Vol 1 + 2** (Alex Xu) — paid book but ByteByteGo channel covers most of it free

## When to Add a Paid Resource

If by **end of Phase 3** you find:

- LC Premium ($35/mo) — useful for company-tag filter when applying. Buy 1 month at start of Phase 5.
- Educative "Grokking the System Design Interview" — $79 lifetime sale sometimes; could supplement Phase 4 if HLD feels stuck
- DSA-coach.com mock packages — only if free mocks aren't enough

**Don't pre-buy** anything before you hit a real ceiling with free resources.
