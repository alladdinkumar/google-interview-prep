# Weekly Schedule — ~9.75 hours, fitted around GATE

The GATE plan owns weekdays 08:30–10:00 and 20:00–21:30, and Saturday 09:00–13:00. Google prep
takes the gaps: the lunch hour, Saturday afternoon, and Sunday morning.

```
            Mon     Tue      Wed     Thu     Fri     Sat              Sun
08:00                                                                 Contest
08:30-10:00 GATE    GATE     GATE    GATE    GATE    GATE 09-13       (08:00-09:30)
                                                                      Review 09:45
13:00-13:45 Lunch   Theory   Redo    Lunch   Lunch
14:00-16:00                                          Learn block
16:15-18:00                                          Practice block
20:00-21:30 GATE    GATE     GATE    GATE    GATE
```

| Slot | Minutes | Rule |
|------|---------|------|
| Lunch drill (Mon, Thu, Fri) | 45 | Timer on. Easy 15, Medium 25, Hard 40 min, then the hint ladder, then the solution video. Log it. |
| Theory lunch (Tue, weeks 1–38) | 45 | First lecture at 1.5×, the reading, a note with the interview follow-up. |
| Redo lunch (Wed) | 45 | A problem from two weeks back, blank file, no old code. |
| Learn block (Sat) | 120 | Lectures, pattern note with a C++ template, one guided problem. |
| Practice block (Sat) | 105 | Three problems timed and aloud · LLD weeks: the project · SD weeks: a timed design. |
| Contest (Sun) | 90 | LeetCode Weekly Contest, live at 08:00 IST; virtual if missed. |
| Weekly review (Sun) | 30 | `reviews/weekly/week-NN.md`, trackers, next Wednesday's redo. |

## When a day goes wrong

- **Missed a lunch:** do not double up the next day. Leave it unticked; the planner shows it.
- **Lost a whole day (travel, illness, a GATE test):** open the day and press **Skip this day**.
  Everything after it moves one day later, the progress you have is untouched, and the end date
  moves by one day. Undo is one tap.
- **Lost a week:** Settings → Schedule → move the start date forward a week.
- **Falling behind repeatedly:** that is a signal about the load (≈29 h/week with GATE), not about
  effort. Skip days honestly rather than compressing.

## Protected

- Sunday after 10:15 is free.
- Sleep: no Google prep after 21:30 — GATE owns the evening and then you stop.
